# artaria_mystery_dungeon - (provisional name)

Dungeon crawling game based on the saga of Mystery Dungeon games.
Based on the Pygame-ce module

# Gameplay loop:
In each screen, the payer is put in a procedurally generated dungeon floor.
There, they must combat enemies, using the items they find at their disposal
to find the stairs to the next floor, repeating the process.

# Features implemented:
- Procedural dungeon generator
- Dungeon renderer given a tileset
- Turn based combat system
